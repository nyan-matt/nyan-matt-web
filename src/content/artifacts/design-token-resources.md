## Standards & Specifications

[Design Tokens Community Group](https://www.designtokens.org/)
The home of the W3C community group working toward an interoperable standard for design tokens.

[Design Tokens Format Module](https://www.designtokens.org/tr/drafts/format/)
The specification for representing design tokens and groups, including types, aliases, composite values, and metadata.

[Design Tokens Resolver Module](https://www.designtokens.org/tr/drafts/resolver/)
An emerging specification for composing token files using sets, modifiers, contexts, and references.

## Tools

[Style Dictionary](https://styledictionary.com/)
Amazon’s open-source build system for transforming design tokens into platform-specific outputs.

[Tokens Studio](https://tokens.studio/)
Token authoring and management tooling with support for sets, themes, references, and synchronization with Figma.

[Figma Variables](https://help.figma.com/hc/en-us/sections/14506605769879-Variables)
Figma’s native system for reusable values, collections, modes, aliases, and variable scopes.
